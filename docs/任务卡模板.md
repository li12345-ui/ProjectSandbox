# Project Sandbox — AI 任务卡模板（Task Card v1.0）

**用途**：AI 执行任务前的唯一指令契约。无卡不开工；卡上未授权的一律不做（对应纪律 1/2：不扩权、≤2 文件）。

## 字段说明

| 字段 | 说明 | 填写要求 |
|---|---|---|
| **编号** | 任务唯一 ID | `TSK-<域>-<序号>`，如 `TSK-DATA-002` |
| **唯一模型** | 执行本卡绑定的模型 | 一卡一模型，中途换模型须开新卡并交评审 |
| **目标** | 本卡要交付什么 | 一句话，动词开头，无二义 |
| **输入** | 可读取的既有资产 | 文件路径 + 关键页/节，禁止引用不存在的输入 |
| **允许修改文件** | 可写清单 | **≤2 个**，路径精确到文件；新建即计入 |
| **禁止** | 明确禁令 | 逐条列：禁动存档格式/网络协议/事件总线、禁第三方库、禁超范围、禁幻觉接口 |
| **输出** | 交付物形态 | 必须含：补丁/文件 + 测试 + 风险说明 + 验收标准 |
| **验收** | 可勾选判据 | 每卡 ≥3 条，全部勾选才算完成，不等同于"测试通过" |

## 空白模板

```markdown
## TSK-<域>-<序号>：<任务名>
- 唯一模型：<模型名>
- 目标：
- 输入：
  - <路径> # <用途>
- 允许修改文件（≤2）：
  1. <路径>
  2. <路径>
- 禁止：
  - 存档格式 / 网络协议 / 全局事件总线
  - 第三方库
  - 超出本卡目标范围
  - <其他专项禁令>
- 输出：<交付物清单，含 补丁/文件+测试+风险+验收>
- 验收：
  - [ ] 判据 1
  - [ ] 判据 2
  - [ ] 判据 3
```
