# ADR-002：冻结引擎与工具链版本（Godot 4.7.2 + .NET SDK 10 + TFM net8.0）

- 状态：已接受
- 日期：2026-10-03
- 决策人：项目所有者（LI12345-ui）
- 取代：ADR-001（仅存于会话记忆、未落盘；其"Godot 4.3 + .NET 8"的锁定建议被本 ADR 推翻）

## 背景

CI 落地（TSK-DATA 系列 + ci.yml）时确认了本地实际环境：

- 用户本地安装 Godot 4.7.2（.NET/mono 风味）
- .NET SDK 10.0.401
- Godot.NET.Sdk/4.7.2 要求 TargetFramework=net8.0；SDK 10 可向下兼容编译 net8.0 目标

为保证「本地开发 / CI runner / 部署产物」三者一致、避免构建漂移，需要把版本组合固化为项目基线。

## 决策

1. Godot：**4.7.2，.NET（mono）风味**。本地与 CI（官方 Release 直下 `Godot_v4.7.2-stable_mono_linux_x86_64.zip`）保持一致。
2. .NET SDK：**10.x stable**（CI 用 `actions/setup-dotnet@v4`，`dotnet-version: "10.x"`）。
3. TargetFramework：**net8.0**（GodotSharp 4.7.2 的兼容 TFM，与 SDK 大版本无关）。
4. 验证基准：CI 首日共 8 次运行，最终 run #8 `conclusion: success` 全绿，版本组合验证通过。

## 后果

- 所有新代码必须在 Godot 4.7.2 + net8.0 下可编译、可冒烟（`Main.tscn` 加载）。
- 任何 Godot 或 .NET SDK 版本变更须新开 ADR 讨论，禁止静默漂移。
- 不再回退 Godot 4.3 / .NET 8 方案。
